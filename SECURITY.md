# Security Policy

## Supported Versions

ESAP is currently in early development and has not published a production-ready release. Security fixes are applied to the latest code on the default branch.

| Version | Supported |
| --- | --- |
| Latest default branch | Yes |
| Older commits and snapshots | No |

## Reporting a Vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, or pull request.

Report it privately through the repository's **Security** tab by selecting **Report a vulnerability**. Include:

- A clear description of the vulnerability
- Steps to reproduce it
- The possible impact
- Any suggested fix or mitigation

If private vulnerability reporting is unavailable, contact the repository owner through their GitHub profile and ask for a private reporting channel. Do not include sensitive vulnerability details in the initial public message.

You should receive an acknowledgement within seven days. The report will be reviewed, its impact assessed, and a fix coordinated before public disclosure when the vulnerability is confirmed.

## Scope

Security reports may include authentication or authorization problems, exposure of restaurant or employee data, payment workflow flaws, dependency vulnerabilities, and other issues that could affect confidentiality, integrity, or availability.

General bugs and feature requests should be submitted through GitHub Issues instead.
